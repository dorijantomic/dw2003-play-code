digimon world 3 · the menu cursors

Four cursors, four clocks

Every menu cursor the disc draws, running at the rate the original code advances it. One tick is one vsync: PAL runs 50 a second, so a 6-vsync step is 120 ms and the pause cursor's rest is 0.64 s. All four rows share one clock, so you can watch them drift against each other. Nothing here is a redrawn approximation of the timing — the numbers come from the same tables the game's own port reads.

vsync 0 0.00 s

The pause row draws the walker's real cursor glyphs (web/uifont.js), the same five strings the pause menu swaps through. The other three rows draw the cursor's shape by hand, because the album and lab art is not part of the cursor table; their colours and clocks are the decoded ones.
