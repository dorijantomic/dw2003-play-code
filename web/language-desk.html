digimon world 3 · boot language screen (cnty_sel)

Seven rows, and the pad reaches five

The language screen runs before the title. It draws seven rows, one per language, and its cursor table writes one language byte per row. Up and Down walk the main list; rows 5 and 6 sit in a side pane that this build never opens. This desk lays out what each row would change — the title menu's clip trio, the END card, the naming keyboard's pages and the name plate — against English, the build every number here comes from.

The USA row changes nothing decoded.

It picks the country/usa pack, but no decoded screen lays out differently: the title trio is 8, 9, 10, the END card is clip 0, the naming keyboard has one page and the plate is the eight-box clip 55. That is the headline of this page, not a flaw.

The seven rows

The cursor table is seven bytes: 02 03 05 04 06 01 00. Rows 0–4 are the PAL EFIGS in alphabetical order — English, French, German, Italian, Spanish. Rows 5 (USA, right side) and 6 (JPN, left side) never light up, because the side pane's mode word (+0x14) is written 0 once and never 1. The Japanese title path is reachable today only with ?skipLanguage=1&language=0.

What each row changes

A row's branches are the decoded layouts that differ from English. English is the reference and branches from nothing; USA is the row that changes nothing decoded; the four other PAL languages each get their own title words and their own END card; Japanese gets exactly three things.

The tables the screens read

None of this is chosen by the country-select code itself: each screen reads the same language byte the row wrote and picks its own table. The name plate is the odd one out — it reads the field length, not the language.
